# Welcome

This site is your study companion for **Multimedia and Application (BCA429CO)**. It follows the official syllabus unit by unit and is written to be enough for the final exam: every syllabus topic gets a full explanation, diagrams, comparison tables, exam tips and practice questions.

!!! source "Where the content comes from"
    The notes follow the previous lecturer's slides and PDFs, expanded into full explanations. Each page says which lecturer file it follows. Where the lecturer's notes stop short of the syllabus, the page says so in a clearly marked box.

## How each unit is organised

Every unit in the sidebar has the same parts.

- **Unit overview**: what the unit covers, which syllabus items it fulfils, and what to expect in the exam.
- **Class slides**: a short slide deck you can follow in class or revise from.
- **Topic notes**: the deep notes. Read these for the exam.
- **Practice questions**: short-answer, long-answer and multiple-choice questions. The answers are hidden until you click them.

Look for these boxes inside the notes:

!!! exam "Exam tip"
    High-yield points: things that are asked often, or that students often get wrong.

!!! source "Source"
    Which lecturer file and pages a section follows.

!!! info "Beyond the lecturer's notes"
    Extra explanation added so the syllabus topic is fully covered.

??? question "Checkpoint: click to reveal the answer"
    Each topic page ends with checkpoint questions like this one. Try to answer in your head first.

## How to study from this site

1. Skim the **unit overview** to see what is coming.
2. Go through the **class slides** once for the big picture.
3. Read the **topic notes** in order. Do each checkpoint before opening the answer.
4. Finish with the **practice questions**, writing full answers on paper before you reveal them.
5. Use the search box (top right) to find any term quickly.
