This deck follows every topic note in order, with diagrams, charts, worked examples, exam-focus recaps and a quick-check quiz at the end. Topics run left to right; press **&darr;** to dive into the detail slides of a topic.

| Key | Action |
|---|---|
| ++arrow-left++ ++arrow-right++ ++arrow-up++ ++arrow-down++ | Move between topics and detail slides |
| ++esc++ | Overview of every slide |
| ++f++ | Full screen |
| ++s++ | Speaker view (opens notes window) |
| ++ctrl+shift+f++ | Search inside the deck |
| ++alt++ + click | Zoom into a diagram |

The deck loads its slide engine from the internet, so you need to be online.
