# Nepali glossary (नेपाली शब्दावली)

English exam terms with a Nepali explanation, to help you understand first and then answer **in English** in the exam.

!!! note "Please verify"
    These Nepali renderings are study aids written by the course author. Technical Nepali terms vary between books, so always write the English term in the exam.

| English term | नेपालीमा (अर्थ) |
|---|---|
| Multimedia | पाठ, तस्बिर, ध्वनि, भिडियो आदि धेरै माध्यमलाई कम्प्युटरद्वारा एकसाथ जोडेर प्रस्तुत गर्ने प्रविधि |
| Medium | जानकारी प्रस्तुत गर्ने वा पठाउने माध्यम |
| Discrete medium | समयमा भर नपर्ने माध्यम (पाठ, स्थिर तस्बिर, ग्राफिक्स) |
| Continuous medium | समयसँग सम्बन्धित माध्यम (अडियो, भिडियो, एनिमेसन) |
| Hypertext | लिङ्कहरूले जोडिएका पाठका खण्डहरू, जसलाई जुन क्रममा पनि पढ्न सकिन्छ |
| Hypermedia | हाइपरटेक्स्टमा तस्बिर, ध्वनि र भिडियो पनि थपिएको रूप |
| Synchronization | विभिन्न माध्यमहरू (जस्तै आवाज र ओठको चाल) समयमा मिल्ने गरी चलाउने काम |
| Analog signal | निरन्तर परिवर्तन हुने संकेत |
| Digital signal | ० र १ को रूपमा भण्डारण गरिएको संकेत |
| Sampling | समय-समयमा संकेतको मान नाप्ने प्रक्रिया |
| Sampling rate | प्रति सेकेन्ड कति पटक नमुना लिइन्छ (Hz) |
| Quantization | प्रत्येक नमुनालाई निश्चित तहमध्ये नजिकको तहमा राख्ने प्रक्रिया |
| Nyquist theorem | उच्चतम आवृत्तिको कम्तीमा दोब्बर दरमा नमुना लिनुपर्छ |
| Aliasing | कम नमुना दरका कारण उच्च आवृत्ति नक्कली न्यून आवृत्ति जस्तो देखिने समस्या |
| Frequency | प्रति सेकेन्ड तरंगको चक्र संख्या |
| Amplitude | तरंगको उचाइ, जसले ध्वनिको चर्को पन निर्धारण गर्छ |
| Bit depth | प्रत्येक नमुनालाई कति बिटमा राखिन्छ |
| MIDI | सङ्गीत बजाउने निर्देशन पठाउने मानक (ध्वनि होइन, आदेश) |
| Pixel | तस्बिरको सबैभन्दा सानो बिन्दु |
| Resolution | तस्बिरको चौडाइ × उचाइ (पिक्सेलमा) |
| Color depth | प्रति पिक्सेल कति बिटले रङ जनाउँछ |
| Bitmap | पिक्सेलको ग्रिडको रूपमा भण्डारण गरिएको तस्बिर |
| Vector graphics | आकारहरूलाई गणितीय सूत्रले वर्णन गर्ने ग्राफिक्स |
| Dithering | थोरै रङ प्रयोग गरेर धेरै रङ जस्तो देखाउने तरिका |
| Frame | भिडियोको एउटा स्थिर तस्बिर |
| Frame rate | प्रति सेकेन्ड देखाइने फ्रेम संख्या (fps) |
| Luminance | रङको चमक (Y) |
| Chrominance | रङको जानकारी (U, V) |
| Animation | स्थिर तस्बिरहरू क्रमशः देखाएर चल्ने भ्रम सिर्जना गर्ने विधि |
| Compression | डेटाको आकार घटाउने प्रक्रिया |
| Lossless compression | मूल डेटा ठ्याक्कै फर्काउन सकिने सङ्कुचन |
| Lossy compression | केही जानकारी सधैंका लागि हटाएर बढी सङ्कुचन गर्ने विधि |
| Entropy coding | डेटाको अर्थ नहेरी, मानहरूको क्रम मात्र हेरेर गरिने सङ्कुचन |
| Run-length coding | दोहोरिएका अक्षरलाई अक्षर र संख्याले जनाउने (aaa → a3) |
| Huffman coding | धेरै आउने चिन्हलाई छोटो कोड दिने सङ्कुचन |
| Prefix property | कुनै कोड अर्को कोडको सुरुवाती भाग हुनु हुँदैन |
| DCT | ८×८ ब्लकलाई आवृत्ति भागमा बदल्ने गणितीय रूपान्तरण |
| Quantization (JPEG) | DCT गुणाङ्कलाई भाग गरी गोलो बनाउने चरण, यही चरणमा डेटा हराउँछ |
| Zigzag scan | ८×८ ब्लकलाई कर्णको क्रममा पढेर शून्यहरू एकै ठाउँ ल्याउने तरिका |
| JPEG | स्थिर तस्बिरका लागि सङ्कुचन मानक |
| MPEG | चल भिडियो र अडियोका लागि सङ्कुचन मानक |
| I-frame | अरू फ्रेममा भर नपर्ने पूर्ण फ्रेम |
| P-frame | अघिल्लो फ्रेमबाट अनुमान गरिएको फ्रेम |
| B-frame | अघिल्लो र पछिल्लो दुवै फ्रेमबाट अनुमान गरिएको फ्रेम |
| CD-DA | डिजिटल अडियो भण्डारण गर्ने कम्प्याक्ट डिस्क |
| CD-ROM | कम्प्युटर डेटा भण्डारण गर्ने कम्प्याक्ट डिस्क |
| DVD | CD भन्दा बढी क्षमताको अप्टिकल डिस्क (रातो लेजर) |
| Blu-ray | नीलो-बैजनी लेजर प्रयोग गर्ने उच्च क्षमताको डिस्क |
| Sector / Block | डिस्कमा डेटा राख्ने सानो एकाइ (२,३५२ बाइट) |
| Real-time system | नतिजा सही हुनुका साथै समयमै आउनुपर्ने प्रणाली |
| Deadline | काम पूरा हुनुपर्ने अन्तिम समय |
| Hard real-time | म्याद चुक्दा गम्भीर क्षति हुने प्रणाली (जस्तै एयरब्याग) |
| Soft real-time | कहिलेकाहीँ म्याद चुके पनि सहन सकिने प्रणाली (जस्तै भिडियो प्ले) |
| Scheduling | कुन काम कहिले चलाउने भन्ने निर्णय |
| EDF | सबैभन्दा छिटो म्याद हुने कामलाई पहिले चलाउने विधि |
| Rate monotonic | छोटो अवधि भएको कामलाई उच्च प्राथमिकता दिने स्थिर विधि |
| Utilization | CPU को कति भाग काममा खर्च हुन्छ (Σ C/P) |
| QoS | सेवाको गुणस्तर (ढिलाइ, जिटर, ब्यान्डविथ आदि) |
| Jitter | ढिलाइमा हुने उतारचढाव |
| Leaky bucket | झोलाबाट पानी चुहिए जस्तै स्थिर दरमा ट्राफिक पठाउने विधि |
| RTP | रियल-टाइम मिडिया पठाउने प्रोटोकल |
| Skew | सम्बन्धित माध्यमहरू बीचको समयको फरक |
| Lip synchronization | आवाज र ओठको चाल मिल्नु (±८० ms भित्र) |
| Dexter model | हाइपरटेक्स्ट प्रणालीको सन्दर्भ मोडल |
| SGML | कागजातको संरचना वर्णन गर्ने भाषा (DTD सहित) |
| MHEG | अन्तिम रूपका मल्टिमिडिया वस्तुहरूको आदान-प्रदान मानक |
| Toolkit | अनुप्रयोग बनाउन पुनः प्रयोग गर्न मिल्ने सफ्टवेयर घटक |
| Storyboard | परियोजनाको पृष्ठ-पृष्ठको योजना चित्र |
