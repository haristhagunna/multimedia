# Glossary

Hover over any abbreviation in the topic pages to see its full form. Key definitions:

| Term | Meaning |
|---|---|
| Medium | Means of distributing and presenting information |
| Multimedia | Computer-controlled, integrated, digital, usually interactive combination of media |
| Discrete medium | Time-independent (text, image, graphics) |
| Continuous medium | Time-dependent (audio, video, animation) |
| Sampling | Measuring an analog signal at regular time intervals |
| Quantization | Mapping each sample to one of a finite set of levels |
| Nyquist theorem | Sample at least twice the highest frequency |
| Lossless / lossy | Original exactly recoverable / some information discarded |
| Entropy coding | Compression ignoring media semantics (RLE, Huffman) |
| Real-time system | Correctness depends on results arriving by their deadlines |
| Jitter | Variation in delay |
| Synchronization | Keeping temporal relations between media |
| QoS | Guaranteed performance parameters (delay, throughput, loss) |
