# Unit 1: Multimedia System

**3 hours · week 1 · syllabus items 1.1, 1.2, 1.3**

This unit lays the vocabulary for the whole course. Every later unit (sound, image, video, compression, storage, networking, synchronization) is a closer look at one box of the picture you build here.

[Open the class slides](slides.md){ .md-button .md-button--primary }

## What you must master

By the end of this unit you should be able to:

1. **Define** multimedia and medium, and tell **discrete** from **continuous** media.
2. **Classify** media into the six categories, using each category's "central question".
3. **Draw and explain** the global structure: the Application, System and Device domains, plus the vertical synchronization layer.
4. **State** the four characteristics and three properties of a multimedia system.
5. **Contrast** asynchronous, synchronous and isochronous transmission.
6. **List** the challenges, desirable features, components and applications of multimedia systems.
