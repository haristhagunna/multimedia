Optical Storage Media

Multimedia and Application (BCA429CO)

Basic technology

  • Spiral track of pits and lands; transition = 1, between = 0s
  • Track pitch 1.6 µm ≈ 16,000 tpi
  • Layers: substrate, reflective, protective
  • Advantages: density, dust-proof, no head crash, error correction

Eight-to-Fourteen Modulation

  • ≥ 2 zeros between ones (laser resolution)
  • ≤ 10 zeros in a row (clock recovery)
  • 8 bits → 14 channel bits (256 of 267 patterns)
  • + 3 merging bits between codewords

Error handling: CIRC

  • Reed-Solomon, two levels: 4 correction bytes per 24 data bytes
  • Interleaving over adjacent frames
  • Corrects bursts of 4,000 bits (≈ 2.5 mm)
  • Interpolates up to 12,300 bits (≈ 7 mm)
  • Error rate ≈ 10⁻⁸

ISO 9660 and CD-ROM/XA

  • ISO 9660: directory tree, path table, 16-block system area
  • XA (Philips, Sony, Microsoft 1988): interleaved media in one track
  • Form 1: 2,048 B + ECC (text, programs)
  • Form 2: 2,324 B, EDC only (audio, video)
  • XA audio levels B and C (ADPCM)

CD-I, Bridge and Photo CD

  • CD-I (Green Book): CD-RTOS, decoder, audio levels A/B/C
  • CD-I Ready: pregap ≥ 182 s
  • Bridge disc: mode 2; plays on XA and CD-I
  • Photo CD: ImagePac, 5 resolutions, 3–6 MB per photo
