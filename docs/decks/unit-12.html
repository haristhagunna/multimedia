Planning and design

  • Limits: hardware, software cost, contents (copyright), skills
  • Storyboard: every screen, sound, navigation
  • Architecture: linear · hierarchical · non-linear · composite
  • User-friendly: easy to learn, effective, prompt feedback

Production, testing, delivery

  • Rights: license before use (nine protected work types)
  • Alpha: in-house · Beta: representative outside users
  • Deliver by CD-ROM or Internet
  • Include media, runtime libraries, drivers, helper programs, installer

Video on demand

  • Server → network → set-top box → TV
  • True VoD: stream per user · Near VoD: staggered starts
  • MPEG-2 ≈ 4–6 Mbit/s per stream; 1 Gbit/s ≈ 250 streams at 4 Mbit/s
  • Textbook material

Video conferencing

  • Point-to-point and multipoint (MCU)
  • Whiteboard, application sharing
  • Delay ≤ 150 ms; lip sync ±80 ms
  • H.320 (ISDN), H.323 · Textbook material

Other application areas

  • Education: CBT, e-learning, simulations
  • Industry: training, kiosks, remote maintenance
  • Digital libraries: metadata, indexing, preservation
  • Entertainment, media editors, trends: streaming, VR/AR, AI, 5G
