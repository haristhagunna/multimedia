Unit 10

Synchronization

Multimedia and Application (BCA429CO)

What is synchronization?

  • Temporal relation between media objects
  • Time-dependent ↔ time-dependent and time-independent
  • Example: sound and picture in TV; lip movement and speech

Basic issues

RelationExample
ContentSpreadsheet → graph
Spatial (layout)Window area on the screen
TemporalVideo + audio of a concert

Intra vs inter; live vs synthetic

Intra-objectInter-object
ConcernsLDUs of one objectBetween objects
Example25 fps → 40 ms per frameA/V, then pictures, then animation

Live: reproduce capture (video conference) · Synthetic: specified artificially (car-race path)

Presentation requirements

  • Skew = time difference of related audio/video LDUs
  • Lip sync: −80 ms … +80 ms
  • Pointer sync: audio ahead 750 ms, pointer ahead 500 ms
  • Timeliness · continuity · latency · jitter

Reference model: why?

  • Several users and levels need synchronization
  • Each layer gives a mechanism through an interface
  • Interfaces specify or enforce temporal relations
  • Layers can be used directly or by the layer above
