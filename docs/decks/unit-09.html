Hypermedia = hypertext + multimedia

History

  • Memex – Vannevar Bush, 1945
  • Hypertext – Ted Nelson, 1965 (Xanadu)
  • HyperCard 1987 · World Wide Web 1989–91

Nodes, links and anchors

  • Node: unit of information (may be composite)
  • Link: source → destination; uni/bidirectional; embedded or external
  • Anchor: active part (word, picture area, video range)
  • Problems: lost in hyperspace → maps, history, bookmarks

SGML

  • ISO 8879 · meta-language for markup
  • DTD defines elements, structure, attributes
  • Logical structure only; layout left to application
  • HTML = SGML application; XML = subset

ODA

  • ISO 8613 · interchange of documents
  • Logical and layout structure; document profile
  • Content: character, raster graphics, geometric graphics
  • Forms FF, PF, FPF

MHEG

  • ISO 13522 · final-form multimedia objects
  • Classes: content, composite, action, link, script, descriptor, container
  • Time, space, interaction → interactive TV (MHEG-5)
