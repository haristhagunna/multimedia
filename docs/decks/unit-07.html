Multimedia Operating System

Multimedia and Application (BCA429CO)

Why a special OS?

  • Continuous media have time constraints (25 fps → one frame per 40 ms)
  • Ordinary OS: fair, but no timing guarantee
  • Needs: real-time processing, resource management, QoS, continuous-media file system, low jitter

Resource management

  • Active: CPU, network adapter · Passive: memory, bandwidth, buffers
  • QoS request → resource requirement
  • Admission control → reserve or reject
  • Guarantees: deterministic (worst case), statistical, best effort

Continuous media resource model (LBAP)

  • M max message size · R max rate · B max burst
  • Messages in interval t ≤ B + R·t
  • Example: R = 25/s, B = 3 → ≤ 53 in 2 s

Periodic task model

  • C compute time · P period · D = P
  • Utilisation U = C / P; total U = Σ C/P
  • Video: 10 ms every 40 ms → U = 0.25
