Data Compression

Multimedia and Application (BCA429CO)

Why compress?

  • Reduce storage, bandwidth and transmitted volume
  • 640×480×8 bit image = 300 KB
  • CD audio: 44.1 kHz × 16 bit × 2 = 1.41 Mbit/s
  • Needs: good quality, low complexity, bounded time

Huffman coding

  • David Huffman, 1951; prefix rule
  • Frequent symbol → short code
  • Merge the two smallest; left = 0, right = 1
  • Time θ(n log n)

Arithmetic, prediction, adaptive

  • Arithmetic: one codeword for a whole string (interval in 0–1)
  • Prediction: code the difference from a predicted value
  • Adaptive: statistics learned while coding (adaptive Huffman, LZW)
  • Prediction and adaptive: textbook material, not in lecturer notes

Loss happens in quantization

DCT and quantization

  • DCT splits a block into frequencies: 1 DC + 63 AC
  • Information sits in low frequencies
  • 64-entry table divides coefficients; high frequencies → 0
  • Zigzag groups the zeros
