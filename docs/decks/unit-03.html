Unit 3Overview

Sound was one stream of numbers over time. An image is a grid of numbers over space. This unit explains how a picture is stored (pixels, bitmaps, colour depth), how it differs from a graphic (a set of drawing instructions), how images are generated (synthesis), understood (analysis and recognition) and sent over a network.

Unit 3 objectivesWhat you must master

  1. Distinguish an image from a graphic, and a bitmap from graphics primitives.
  2. Calculate the storage of a bitmap from its width, height and bits per pixel.
  3. Explain the capturing, storage and graphics formats, and name common file formats.
  4. Describe image synthesis, the three-part interactive graphics framework, raster display hardware and dithering.
  5. Explain image analysis and the steps of image recognition.
  6. Describe the three ways of transmitting an image (raw, compressed, symbolic) and calculate raw image size.

Image and Graphics BasicsBitmap vs vector

Bitmaps store every pixel (resolution-dependent); vectors store geometric descriptions (resolution-independent).

Image and Graphics BasicsWhat is an image?

An image is a spatial representation of an object: a two-dimensional or three-dimensional scene, or another image. Abstractly, an image is a continuous function defining a rectangular region of a plane.

Where it appears Form of the image
Recorded image Photograph, analog video signal, or digital format
Computer vision Video image, digital image or picture
Computer graphics Digital image
Multimedia All of the above
Source note: Image and Graphics Basics

What is an image?The digital image

A digital image is a matrix of numeric values given by the function I(r, c), where r and c are the row and column of a point.

  • The point is called a pixel.
  • I(r, c) is the intensity value (gray level) at that point.
  • Gray scale for a monochrome picture: 0 and 1. For an 8-bit image: 0 to 255.
  • The number of pixels is the resolution.

Image and Graphics BasicsColour bitmaps (1/2)

To show colour you need more bits per pixel. The number of colours is 2 raised to the bits per pixel.

8 2⁸ = 256 Pseudo colour (one byte per pixel)
24 2²⁴ = 16,777,216 True colour (three bytes per pixel)

In 24-bit colour each byte holds the intensity of one primary colour: Red, Green and Blue, each with 256 levels (256 × 256 × 256 colours).

The depth of an image is the number of bits used to represent each pixel.

Check yourself

Differentiate an image and a graphic in two points.

A graphic is stored as objects (lines, curves, circles) with semantics, so objects can be edited individually and the file is small but needs processing before display. An image is a bitmap of pixels that ignores semantics, needs more storage, and is displayed without processing.

Image and Graphics FormatsImage and Graphics Formats

Two kinds of two distinct kinds of image format: the format in which the image is created during digitising (capturing format), and the format in which images are stored and often transmitted (storage format). Graphics formats are a separate case.

Source note: Image and Graphics Formats

Image and Graphics FormatsImage capturing format

The format is specified by two main parameters:

  1. Spatial resolution, indicated in pixels (pixels × pixels).
  2. Colour encoding, specified by bits per pixel.

The values of both depend on the hardware and software used to input and output images.

  • Example: a SPARCstation captures images at 320 × 240.
  • Colour encoding may be 1 bit, 8 bits or 24 bits.
Source note: Image and Graphics Formats

Image and Graphics FormatsImage storage format

The image is stored as a two-dimensional matrix in which each value corresponds to the data for one pixel.

  • In bitmaps the values are binary numbers.
  • In colour images it is good to store RGB triples (red, green and blue components).
  • Example: a 640 × 480, 24-bit colour image needs 900 KB (921,600 bytes).

Image Synthesis and Graphics SystemsComputer image processing (1/2)

Two linked ideas, opposite in direction:

  • Computer graphics is the pictorial synthesis of real or imaginary objects from their computer-based models.
  • Image processing is the converse: analysis of scenes, or reconstruction of models from pictures of 2D and 3D objects.

Computer image processing therefore has two parts: image synthesis (generation) and image analysis (recognition).

Source note: Image Synthesis and Graphics Systems

Image Synthesis and Graphics SystemsComputer image processing (2/2)

Source note: Image Synthesis and Graphics Systems

Image Synthesis and Graphics SystemsImage synthesis

Image synthesis deals with the generation of images of real or imaginary objects. It is an integral part of all computer user interfaces and is indispensable for visualising 2D, 3D and higher-dimensional objects.

Image Synthesis and Graphics SystemsFramework of an interactive graphics system

The high-level framework of almost any interactive graphics system (for example SRGP) has three software components. Some sources add a fourth part, the graphics hardware.

Source note: Image Synthesis and Graphics Systems

Framework of an interactive graphics system1. Application model

  • Represents the data or objects to be pictured on the screen.
  • Typically stores descriptions of primitives that define the shape of components, the object attributes, and connectivity relationships describing how the components fit together.
  • Stored in an application database.
  • It is application-specific and created independently of any display system.
Source note: Image Synthesis and Graphics Systems

Framework of an interactive graphics system2. Application program

Converts the primitive descriptions in the application model into the procedure calls or commands the graphics system uses to create an image. This takes two steps:

  1. Extraction of the portions to be viewed from the application database, using a selection or query system.
  2. Conversion of the extracted geometry into the proper format.

The program produces views by sending the graphics system a series of graphics output commands.

Source note: Image Synthesis and Graphics Systems

Framework of an interactive graphics system3. Graphics system

The intermediary between the application program and the display hardware, responsible for actually producing the picture. It performs two kinds of transformation:

  • Output transformations: from objects in the application model to a view of the model.
  • Input transformations: from user actions to application-program inputs that cause the model and/or picture to change.

Graphics hardwareInput devices

  • 2D input: mouse, keyboard, data tablet, touch-sensitive panel on the screen.
  • 3D and higher-dimensional input: trackballs, spaceballs, data glove.
  • Even audio communication can provide input.

Output: the raster display

Modern visual output uses raster display devices, which display primitives in special buffers called refresh buffers as pixel components.

Source note: Image Synthesis and Graphics Systems

Graphics hardwareOutput: the raster display (2/4)

  • A raster display uses a CRT with rows of phosphor dots; electron guns at the back make the dots glow when hit.
  • The complete display is a raster of horizontal raster lines, each made of pixels.
  • The electron beam moves across the screen one row at a time, top to bottom. The picture information is held in the refresh buffer.
  • The video controller reads the refresh buffer and produces the image, turning the phosphor spots on and off according to the image data. It samples the entire screen line by line.
  • After each row the beam returns to the start of the next row: this is the horizontal retrace.
Source note: Image Synthesis and Graphics Systems

Graphics hardwareOutput: the raster display (3/4)

  • A display controller receives and interprets the sequence of output commands. In low-end systems such as personal computers it is implemented in software, as part of a graphics library, and the refresh buffer is part of CPU memory.

A typical diagram shows the computer host interface sending display commands to the display controller, which writes the scanned image into the refresh buffer; the video controller reads that buffer and drives the monitor; mouse and keyboard send interaction data back to the display controller.

Image Synthesis and Graphics SystemsDithering

Dithering is a process used in output devices (monitor screens and some printers) to produce shades of gray or tints of colour. The aim is an effect as close to the original image as possible while using fewer colours.

It relies on the eye's spatial integration: if we view a very small area from a large enough distance, the eye averages the fine detail and records only the overall intensity.

Dithering is usually called halftoning, and the shades of gray are called halftones.

Source note: Image Synthesis and Graphics Systems

DitheringDither matrix

If a pixel is replaced by an m × n dither matrix (an array of dots), the pixel can show intensity levels from 0 to m × n (that is, the number of dots lit).

A 2 × 2 matrix can represent 5 intensity levels: none, one, two, three or all four dots lit.

Two techniques

Clustered-dot ordered dithering (halftoning) Dispersed-dot ordered dithering
How it works Four adjacent pixels represent the intensity of a single colour; lighting none, one, two, three or all four gives different intensities Uses a 2 × 2 dither pattern with halftone patterns as in the clustered method
Used for Devices that cannot display individual dots, e.g. laser printers Devices that can display individual dots, e.g. CRT displays
Result Different intensities of a colour A colour CRT shows 125 colours

Image Analysis and RecognitionImage analysis

Image analysis is concerned with techniques for extracting descriptions of objects from images. In some textbooks' terms, image-processing algorithms alter an input image to create a new image, or extract image descriptions (shape, position, orientation) for higher-level analysis.

Analysis techniques include:

  • Computation of perceived brightness and colour.
  • Partial or complete recovery of 3D data in a scene.
  • Location of discontinuities that correspond to objects in the scene.
  • Characterisation of the properties of uniform regions in the image.

It may also deal with calculating and comparing intensity, hue and saturation, the centroid, identifying noise, detecting patterns, or recognising the image itself.

Image Analysis and RecognitionImage recognition (1/2)

To fully recognise an object in an image means knowing that there is agreement between the sensory projections and the observed image. How the object appears is given by the spatial configuration of the pixel values, so the observed configuration must agree with the expected one.

This requires two capabilities:

  1. Infer the object's position and orientation from the spatial configuration. That means working out which pixels belong to the object, and distinguishing features such as special markings, curves and lines.
  2. Confirm the inference is correct by matching distinguishing image features with the corresponding object features.
Source note: Image Analysis and Recognition

Image Analysis and RecognitionImage recognition (2/2)

The difficulty of recognition depends on the kind of object, the background, the imaging sensor and similar factors. A simple corner extraction can identify some images.

Compare with audio and video

An image is a discrete medium (no time component), so its transmission needs reliable, bursty transport rather than the steady, on-time delivery that continuous media need. This links back to Media Concepts.

The image size depends on the representation format used for transmission.

Three ways to send an image1. Raw image data transmission

The image is generated by a video digitiser and transmitted in its digital format.

Size=Spatial resolution×Pixel quantization\text{Size} = \text{Spatial resolution} \times \text{Pixel quantization}Size=Spatial resolution×Pixel quantization

Example: a 640 × 480 image with 8 bits per pixel:

640×480×8=2,457,600 bits=307,200 bytes640 \times 480 \times 8 = 2{,}457{,}600 \text{ bits} = 307{,}200 \text{ bytes}640×480×8=2,457,600 bits=307,200 bytes

2. Compressed image data transmission

The image is generated by a video digitiser and compressed before transmission.

  • Methods such as JPEG or MPEG are used.
  • The reduction in size depends on the compression method and compression rate.
Source note: Image Transmission

Three ways to send an image3. Symbolic image data transmission

The image is represented by symbolic data: image primitives (for example 2D or 3D geometric representation), attributes and other control information.

  • This representation is used in computer graphics.
  • The image size equals the size of the structure that carries the symbolic information.

Check yourself

Why is image transmission 'bursty' and why is timing not critical?

Images are large, so they are sent as bursts of data. An image has no time component, so unlike audio and video it does not need steady, on-time delivery. It does need reliable transport.

Quick check 1 / 616. Which is true of a bitmap compared with graphics?

  • A. It needs less storage
  • B. It needs no processing before display
  • C. Its objects can be individually moved
  • D. It stores primitives and attributes
Answer: B. A, C and D describe graphics.

Quick check 2 / 617. A 16 × 16 monochrome bitmap needs

  • A. 16 bytes
  • B. 32 bytes
  • C. 256 bytes
  • D. 2,048 bytes
Answer: B. 256 pixels × 1 bit = 256 bits = 32 bytes.

Quick check 3 / 618. How many colours does an 8-bit pixel allow?

  • A. 8
  • B. 128
  • C. 256
  • D. 65,536
Answer: C. 2⁸ = 256.

Quick check 4 / 619. Which pair describes graphics formats?

  • A. Pixels and resolution
  • B. Primitives and attributes
  • C. Dpi and bit depth
  • D. Fields and frames
Answer: B. Graphics formats are specified through primitives (lines, circles, polyhedra) and attributes (line style, width, colour).

Quick check 5 / 620. Which technique suits devices that cannot display individual dots, such as laser printers?

  • A. Dispersed-dot ordered dithering
  • B. Clustered-dot ordered dithering
  • C. Edge detection
  • D. Pulse code modulation
Answer: B. Dispersed-dot dithering is for devices (such as CRTs) that can display individual dots.

Quick check 6 / 621. In image recognition, which step compares objects with stored models?

  • A. Conditioning
  • B. Labeling
  • C. Extracting
  • D. Matching
Answer: D. Matching compares each object with stored models and selects the best match.
