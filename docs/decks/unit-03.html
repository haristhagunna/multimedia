Image and Graphics

Multimedia and Application (BCA429CO)

What is an image?

  • Spatial representation of an object or scene
  • Digital image = matrix of values I(r, c)
  • Pixel: smallest addressable element
  • Bitmap: the array of pixels; resolution = number of pixels

Image and graphics formats

  • Capturing: spatial resolution + bits per pixel
  • Storage: 2D matrix; GIF, JPEG, TIFF, PNG, BMP
  • Graphics: primitives (line, circle...) + attributes (style, width, colour)
  • Pros: less data, easy editing · Con: conversion to pixels
  • Packages: SRGP, PHIGS, GKS

Raster display

  • CRT: phosphor dots, electron gun
  • Refresh buffer holds the image
  • Video controller reads it row by row, top to bottom
  • Horizontal retrace between rows
  • Display controller interprets commands

Dithering (halftoning)

  • Shades from fewer colours; uses the eye's spatial integration
  • Clustered-dot: laser printers · Dispersed-dot: CRTs
  • 2 × 2 matrix → 5 intensities
  • R, G, B: 5 × 5 × 5 = 125 colours
