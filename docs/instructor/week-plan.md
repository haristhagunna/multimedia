## Per-session pattern (about 50 minutes)

1. **5 min**: retrieval question from the previous session.
2. **25 min**: teach from the class slides; stop at each *Check yourself* slide.
3. **10 min**: one simulator or worked numerical, done live.
4. **10 min**: students attempt two practice questions on paper; reveal and mark.

## Revision weeks

Use [Mock Exam 1](../revision/mock-exam-1.md) as a timed class test and give [Mock Exam 2](../revision/mock-exam-2.md) as homework. Hand out the [cheat sheets](../revision/cheat-sheets.md).
