## Short answer

??? question "1. Define a multimedia document and a document architecture. (3 marks)"
    A multimedia document combines discrete and continuous media with spatial, temporal and logical relations. A document architecture defines how it is structured and represented so it can be edited, exchanged and presented.

??? question "2. Differentiate logical and layout structure. (3 marks)"
    Logical: meaning (chapter, section). Layout: presentation (page, columns, fonts).

??? question "3. Differentiate hypertext, hypermedia and multimedia. (5 marks)"
    Hypertext: linked text nodes. Hypermedia: linked nodes of any media. Multimedia: integrated media, not necessarily non-linear.

??? question "4. Who proposed the Memex and who coined 'hypertext'? (2 marks)"
    Vannevar Bush (1945) the Memex; Ted Nelson (1965) the term hypertext.

??? question "5. What are node, link and anchor? (3 marks)"
    Node: information unit. Link: connection between source and destination. Anchor: the active part inside a node.

??? question "6. State two problems of hypermedia and remedies. (4 marks)"
    Disorientation and cognitive overload; maps, history, bookmarks, guided tours.

??? question "7. What is a DTD? (2 marks)"
    The Document Type Definition of SGML: allowed elements, structure and attributes.

??? question "8. What is MHEG used for? (3 marks)"
    Interchange of final-form multimedia objects, mainly interactive TV and set-top boxes.

## Long answer

??? question "9. Explain the Dexter hypertext reference model. (7 marks)"
    Run-time, storage and within-component layers; presentation specification and anchoring interfaces.

??? question "10. Explain SGML with an example. (7 marks)"
    Meta-language, markup of logical structure, DTD, instance, entities, HTML/XML relation; the book/chapter example.

??? question "11. Explain ODA. (6 marks)"
    Logical and layout structure, document profile, content architectures, formats FF/PF/FPF, ODIF.

??? question "12. Explain the MHEG object classes. (7 marks)"
    Content, composite, action, link (condition–action), script, descriptor, container, macro; engine; final form.
