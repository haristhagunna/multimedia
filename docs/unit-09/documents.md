## What is a document?

A **document** is a **structured** collection of information intended for presentation to a reader. A **multimedia document** combines **discrete media** (text, graphics, images) and **continuous media** (audio, video, animation) with **temporal, spatial and logical relations** among them.

## Document architecture

A **document architecture** defines how the document is **structured and represented** so that it can be created, edited, exchanged and presented on different systems. It separates three things:

| Structure | Describes |
|---|---|
| **Logical structure** | The **meaning-based organisation**: chapters, sections, paragraphs, figures, captions |
| **Layout structure** | The **presentation**: pages, columns, fonts, positions on the output device |
| **Content** | The data itself: character text, raster or geometric graphics, audio, video |

A multimedia architecture adds the **temporal structure** (when each object is presented) and **hyperlinks** (see [Hypertext](hypertext.md)).

### Forms of a document

- **Formatted form:** ready to present; cannot be edited easily (like a printout).
- **Processable form:** carries the logical structure, so it can be edited and reformatted.
- **Formatted processable form:** both.

## Manipulation of multimedia data

Operations on multimedia documents:

1. **Creation and capture** of media objects (scanning, recording).
2. **Editing**: cut, copy, paste, rearrange; edit the structure.
3. **Integration**: combine media (**authoring tools**); specify layout, time and interaction.
4. **Storage and retrieval**: databases, indexing and search of text, image, audio and video.
5. **Transformation and conversion**: change format and resolution; compress.
6. **Presentation and interchange**: formatting, play-out, and transfer between systems using a **standard** (SGML, ODA, MHEG).

!!! exam "Exam tip"
    "Why are document architectures needed?" Answer: interchange between different systems and editors, separate logical content from layout, reuse, and consistent presentation.

## Checkpoint

??? question "Differentiate logical and layout structure."
    Logical: meaning (chapter, paragraph). Layout: appearance (page, font, position).

??? question "Which form of a document can be re-edited?"
    The processable form.
