# Security policy

This is a static educational website with no login, forms, database or user data. Progress is stored only in your own browser (localStorage) and is never sent anywhere.

To report a security concern, open a private report via the repository's **Security → Report a vulnerability** tab, or email the author. Please do not post exploit details in public issues.
